# 经验正文格式与沉淀细节（沉淀经验时按需读取）

写新经验条目、或整理知识库时读这里；日常执行只需按 AGENT_GUID §7 的触发条件命中后读正文。

## 正文格式（lessons/<分类>-<简述>.md）
```markdown
# <一句话标题>
trigger: <什么情况下会再遇到（加载条件，写具体场景）>
scope: <适用环境/项目，如 windows / 全部>

## 错误表现
<当时怎么错的，原始报错/命令>

## 正确做法
<应该怎么做>

## 原因
<为什么，简短>
```

## 索引行格式（INDEX.md，每条一行）
`- [触发条件] 一句话结论 → lessons/文件`

## 分类
`env`（环境差异）/ `code`（代码写法）/ `test`（测试写法）/ `tool`（工具用法）。

## 纪律
- 索引行保持一行、简短；正文超过 ~60 行应拆分。
- `INDEX.md` 与 `lessons/` 跨项目共享，写条目时 `scope` 标明适用范围，勿把项目特例当通用规律。
- 定期（如索引超过 30 条时）合并相近条目、删除已失效条目。
